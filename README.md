# princemhizha.github.io

Personal portfolio website built with React, Vite, Tailwind CSS, and Framer Motion.

## Development

- Install dependencies: `npm install`
- Start dev server: `npm run dev`
- Build production: `npm run build`
- Preview production build: `npm run preview`

## Deployment (GitHub Pages)

- This repo is configured for GitHub Pages at `https://princemhizha.github.io`.
- Deploy command: `npm run deploy`

The deploy script publishes the `dist` directory to the `gh-pages` branch.
